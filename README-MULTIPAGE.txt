Upload all HTML files and the complete assets folder to the root of your GitHub repository. Keep emeka-gold.png and chapters-4-5-promo.png in the same root folder as the HTML files. Do not rename or move assets. Commit the changes; Vercel will deploy the multi-page website automatically.


MOBILE COMPATIBILITY UPDATE
All main pages, the digital portfolio, and the three demonstration websites include responsive styling for phone and tablet screens. Navigation is horizontally scrollable on narrow screens, content grids collapse into readable columns, and images/buttons are constrained to the viewport.
